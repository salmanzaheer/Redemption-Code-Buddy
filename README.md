# Redemption Code Buddy

Generate redemption codes quickly.

## Installation

I recommend running locally on a virtual machine.

```bash
python -m venv venv
source venv/bin/activate # /venv/Scripts/activate for windows (or something similar)
pip install flet
```

## Usage

```bash
python main.py
```
